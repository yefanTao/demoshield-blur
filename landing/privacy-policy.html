DemoShield Blur — Privacy Policy

Effective Date: November 26, 2026 · Extension Version: 1.0.0
Short version: DemoShield Blur collects, stores, transmits, and sells zero user data. Every blur, solid redaction, regex scan, and Pro license verification runs 100% locally inside your Chrome browser.

1. Zero Host Permissions & On-Demand Execution

DemoShield Blur requests only four minimal Manifest V3 permissions: activeTab, storage, scripting, and contextMenus. It does not request host_permissions, <all_urls>, tabs, cookies, or webRequest. The extension only accesses the current active tab when you explicitly click the toolbar icon, press Alt+Shift+B, or select a context menu item.

2. Local-Only Regex Scanning & Storage

All pattern matching for emails, API keys, currency figures, phone numbers, and payment cards happens locally in your browser via extension/rules.js. No page text, DOM snapshots, URLs, or usage telemetry are ever sent to remote servers or third-party AI APIs. Your preferences and opt-in per-origin CSS selector rules are stored exclusively in your browser's local chrome.storage.local.

3. Offline Pro License Verification

Optional Pro lifetime license keys (DSPRO-XXXX-XXXX-XXXX) are validated offline using a deterministic checksum inside extension/rules.js with zero phone-home requests.

4. Contact

If you have any security or privacy questions, reach out via the contact form on our website.
